HVCARDS V1.5 — Brand Identity

1. Upload index.html and the entire assets/ directory to the root of the Sport_cards GitHub repository.
2. Keep your CURRENT cards.json and SportCards/ directory unchanged. V1.5 uses the V1.4 data schema.
3. Commit the files, let GitHub Pages publish, then reload with Ctrl+F5.
4. Social link previews contain only HVCARDS branding, no personal profile data. Facebook may cache an older preview. To request a refresh, use https://developers.facebook.com/tools/debug/ with the website URL.

Assets: hvcards-logo.webp (full design), hvcards-emblem.webp (header and detail), favicon.ico and favicon.png, social-preview.jpg (1200x630).
The last gold/crimson trading-card emblem from the logo concept conversation is used. Instagram remains a header link only; buy/trade in card detail still points to Facebook.
No cards.json is bundled to prevent overwriting the current collection.
